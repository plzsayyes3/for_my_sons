# ゆっくり弾幕 v1

For My Sons向けの無料ブラウザ弾幕STGです。

## 使用素材
- キャラクター: たぬき式ゆっくり（たぬき霊夢 / たぬき魔理沙）
  - https://tanukiyukkuri.github.io/tanukitachie/
  - 配布元規約に基づき、ゲーム用PNGを同梱
  - 東方Project由来キャラクターのため、東方Project二次創作ガイドラインに従う
- BGM: Dark Shrine Loop / qubodup
  - https://opengameart.org/content/dark-shrine-loop
  - CC0

## 操作
- iPhone / iPad: タッチパッド操作（デフォルト）または直接タッチを選択
- タッチパッド: 画面下部で指を動かした分だけ相対移動
- 直接タッチ: 触れた位置へ追従
- 操作方式は端末に保存
- PC: 矢印 / WASD
- Shift: 低速 + 当たり判定表示
- 射撃: 自動
